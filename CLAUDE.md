# Инструкции для Claude

## Актуальная концепция (с 17.10.2026): «Professor»

Канал теперь — **Профессор рассказывает о психологии человека в повседневной жизни и ситуациях**. Больше **не сравниваем людей с животными** и не используем рамку «Specimen / полевой журнал / PERFECTLY HUMAN». Всё на английском для аудитории США; владельцу отвечай по-русски. Термины и факты — только из подтверждённых источников (каждый проверять поиском, источники в `sources` и в описании). Исследования спорные — формулируй осторожно (*"some research suggests"*).

- **Форматы:** Shorts 45 с – 2 мин (`format: "short"`) и длинные 8–15 мин (`format: "long"`, длинные делятся на главы по 1–2 минуты с чередованием кадров, как в шортсе).
- **Стиль и инструменты:** `docs/professor-style.md` (слои, кадры, камера, переходы, правила слов-меток). Образец: `episodes/p001-phantom-vibration.json`, собирается `tools/episodes/p001.py`. Номера роликов: `pNNN-<name>`.
- **Персонаж:** статичные вырезы из листов `assets/prof-source/` (`python3 tools/prof/assets.py`), анимация — моушен-дизайн: смена кадра каждые ~2 с, наезды камеры, плашки с источниками, графики, переходы. Палитра: графит, бумага и один жёлтый акцент. Русский текст на панелях листа не использовать.
- **Новые листы персонажа:** `assets/prof-source/kling-sheet-1..10.webp` (Kling AI 3.0, крупнее и чётче первых). Использовать в СЛЕДУЮЩИХ роликах для поз и крупных планов; правила (водяной знак, «абракадабра»-текст, «поплывшие» версии не брать) — в `assets/prof-source/README.md`.
- **Голос:** Kokoro `af_heart` (тон `prof`, финальная мысль `prof-soft`). Не менять без запроса владельца.
- **Сборка:** `npm run make -- <id> --browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell --concurrency=4 --crf=24` (без `--crf` файл выходит в десятки раз тяжелее). Контрольные кадры: `node tools/stills.mjs` + `python3 tools/prof/sheet.py`.
- **Проверка перед отправкой:** нулевой кадр уже с картинкой; плашки не лезут на субтитры (`y` 0.66–0.76); слова-метки сработали на нужных словах (`"Is"` ловит «So **is**»: используйте `"Is#2"`); музыка Kevin MacLeod — строка-атрибуция в описании. Пакет публикации `publish/pNNN-*.md`.

Всё ниже в этом файле описывает **прежний** формат «Specimen: You» (`sNNN`) и «Иллюстрированный учебник» (`epNNN`). Он оставлен для справки и для существующих роликов.

Это фабрика скетч-мультиков для американского YouTube-канала **Specimen: You** — «природной документалки» о людях. Мягкий, негромкий голос исследователя (Kokoro `af_heart` — владелец выбрал его как самый человечный; не менять без запроса) спокойно изучает бытовое поведение человека, даёт ему номер и латинское название, объясняет реальную психологию и ставит печать **PERFECTLY HUMAN**. Концепция — `docs/concept.md`, оформление и тексты канала — `docs/channel.md`. Владелец канала пишет по-русски; ролики — на английском для аудитории США. Отвечай владельцу по-русски.

## Когда просят новый ролик

1. **Тема:** узнаваемая каждому бытовая ситуация + реальный психологический эффект с исследованием. Идеи — в `docs/ideas.md`. Никаких поп-психологических мифов; если исследования спорные — формулируй осторожно (*"some research suggests"*). Источники — в поле `sources`.
2. **Сценарий** `episodes/sNNN-<common-name>.json` по формату `docs/script-format.md`, образец — `episodes/s001-doorway-forgetter.json`. Следующий номер — по порядку после последнего файла в `episodes/`. Структура шортса (подробно в `docs/concept.md`):
   - хук: *"Ever [ситуация]? Congratulations. You're Specimen [00N.|zero zero N.]"* — карточка вида (`card`) шлёпается на слове `specimen`, первый кадр уже с картинкой;
   - *"Observe. The specimen..."* — серьёзное наблюдение, юмор через дедпан, сноски `label` «fig. 1: ...»;
   - поворот;
   - field note: название эффекта + исследование (`quote`);
   - вывод тоном `deep`;
   - вердикт тоном `funny`: шутка-колбэк + *"Perfectly human."* с карточкой и `stamp` на слове `perfectly`.
   Операторская работа обязательна: наезды/отъезды `camera.keys` на ключевых словах (наезд на лицо в момент шутки, отъезд перед карточкой), переходы `black` перед field note и выводом, `zoom`/`fade` в остальных местах, `ambience` для звуков среды. Музыка: один из треков `public/music/` под настроение (`dreamer.mp3`, `easy-lemon.mp3`, `thinking-music.mp3`, `gymnopedie-no-1.mp3`) — это Kevin MacLeod, CC-BY 4.0: в описание ролика обязательно добавить строку-атрибуцию из `public/music/LICENSE.md`.
   **Длина не ограничена** — тема раскрывается полностью (сейчас 60–70 с), но каждые 3–5 секунд должно происходить что-то новое. Обязательные приёмы удержания — таблица в `docs/concept.md` (открытая петля, эксперимент с конкретикой, поворот, бонус-факт, практический совет, колбэк). Ключевые слова в `*звёздочках*`, числа через `[4%|four percent]`. Рассказчик никогда не шутит открыто — смешно за счёт серьёзности. Подача мягкая и неторопливая. Латинское название вида — смешное, но правдоподобное.
3. **Язык:** живой разговорный американский английский, короткие предложения, никакой канцелярщины. Юмор — наблюдательный, добрый, без высмеивания групп людей. Темы и лексика для взрослой аудитории (канал НЕ «для детей»).
4. **Визуал:** каждая сцена показывает то, что звучит. Эмоции через `face` + `pose` + `emote`, изменения во времени через `then` / cue-слова. Пометки красной ручкой (`notes`) — для акцентов и шуток. Следи, чтобы предметы не перекрывали голову персонажа (x-позиции разнести минимум на ~0.3).
5. **Регистрация:** добавить импорт в `src/episodes.ts`.
6. **Сборка:** `npm run make -- <id>` (в облачном контейнере добавь `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`). Проверь `npm run typecheck`.
7. **Проверка глазами:** вытащи 6–10 кадров через ffmpeg (`select=eq(n\,FRAME)`) и посмотри: ничего не обрезано, субтитры читаются, эмоции соответствуют тексту. Только потом отправляй MP4 владельцу.
8. Каждый факт проверяй поиском перед использованием (исследования бывают отозваны — так случилось с Ariely & Wertenbroch 2002, его не использовать).
9. Субтитры уже вшиты в видео — отдельные `.srt` в YouTube НЕ загружать (белые субтитры YouTube закроют наши). Для каждого ролика сделай пакет публикации `publish/<id>.md` по образцу `publish/s001-doorway-forgetter.md` (название с хуком + `| Specimen #00N`, описание с источниками и атрибуцией музыки, 3–5 хэштегов, теги, закреплённый комментарий), и отметь вид в `docs/ideas.md` как ✅.

## Второй стиль: «Иллюстрированный учебник» (Everyday Psychology)

Если владелец просит ролик «в стиле учебника / как ep001», используй стиль из `docs/textbook-style.md`: один разворот-таблица из панелей (`page` в сценарии), камера ездит по панелям, сцены типа `page` с `transition: "cut"`, иллюстрации — компоненты в `src/textbook/art/`. Образец: `episodes/ep001-night-thoughts.json`, раскадровка и реестр источников — `docs/ep001-night-thoughts.md`. Метафоры подписывать как метафоры, анатомию — как упрощение; бытовое беспокойство отделять от клинических симптомов. Номера таких роликов — `epNNN-<name>`. Контрольные кадры: `node tools/stills.mjs <id> <кадры...> --browser-executable=...`.

## Технические заметки

- Длительность сцены = длина озвучки + пауза тона; `public/voice/<id>/manifest.json` содержит тайминги слов и огибающую громкости.
- Озвучка кэшируется по хэшу текста/голоса/скорости; `--force` перегенерирует всё.
- Стиль задаётся в `src/theme.ts` (цвета) и `src/components/ink.tsx` (двойной карандашный штрих, «дрожание» линий, штриховка, бумага). Не добавляй ярких цветов: только графит, бумага, красная ручка, жёлтый маркер.
- `sketch-sheet` в Studio — справочник поз, лиц и предметов.
