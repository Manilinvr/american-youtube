# Инструкции для Claude

Это фабрика скетч-мультиков для американского YouTube-канала о **психологии повседневности**. Владелец канала пишет по-русски; ролики — на английском для аудитории США. Отвечай владельцу по-русски.

## Когда просят новый ролик

1. **Тема:** узнаваемая каждому бытовая ситуация + реальный психологический эффект с исследованием. Идеи — в `docs/ideas.md`. Никаких поп-психологических мифов; если исследования спорные — формулируй осторожно (*"some research suggests"*). Источники — в поле `sources`.
2. **Сценарий** `episodes/<id>.json` по формату `docs/script-format.md`, образец — `episodes/doorway-effect.json`. Структура шортса (подробно в `docs/concept.md`):
   - 0–2 с хук-вопрос (*"Have you ever...", "Why do we always..."*), первый кадр уже с картинкой;
   - усиление ситуации + шутка;
   - поворот (*"It's not you. It's..."*);
   - психология + название эффекта (часто сцена `quote` с названием);
   - мудрый вывод тоном `deep`;
   - юмор-колбэк или петля к хуку.
   60–80 слов, сцены по 2–5 секунд, ключевые слова в `*звёздочках*`, числа через `[4%|four percent]`.
3. **Язык:** живой разговорный американский английский, короткие предложения, никакой канцелярщины. Юмор — наблюдательный, добрый, без высмеивания групп людей. Темы и лексика для взрослой аудитории (канал НЕ «для детей»).
4. **Визуал:** каждая сцена показывает то, что звучит. Эмоции через `face` + `pose` + `emote`, изменения во времени через `then` / cue-слова. Пометки красной ручкой (`notes`) — для акцентов и шуток. Следи, чтобы предметы не перекрывали голову персонажа (x-позиции разнести минимум на ~0.3).
5. **Регистрация:** добавить импорт в `src/episodes.ts`.
6. **Сборка:** `npm run make -- <id>` (в облачном контейнере добавь `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`). Проверь `npm run typecheck`.
7. **Проверка глазами:** вытащи 6–10 кадров через ffmpeg (`select=eq(n\,FRAME)`) и посмотри: ничего не обрезано, субтитры читаются, эмоции соответствуют тексту. Только потом отправляй MP4 владельцу.
8. Для каждого ролика предложи **title** (до 60 символов), **описание** с источниками и 3–5 хэштегов.

## Технические заметки

- Длительность сцены = длина озвучки + пауза тона; `public/voice/<id>/manifest.json` содержит тайминги слов и огибающую громкости.
- Озвучка кэшируется по хэшу текста/голоса/скорости; `--force` перегенерирует всё.
- Стиль задаётся в `src/theme.ts` (цвета) и `src/components/ink.tsx` (двойной карандашный штрих, «дрожание» линий, штриховка, бумага). Не добавляй ярких цветов: только графит, бумага, красная ручка, жёлтый маркер.
- `sketch-sheet` в Studio — справочник поз, лиц и предметов.
