# Листы персонажа «Профессор» (исходники)

| Файл | Что это |
|---|---|
| `sheet-a.webp`, `sheet-b.webp` | Первые листы (чистые линии, 1536×1024). Из них вырезаны текущие PNG в `public/prof/` (`python3 tools/prof/assets.py`). |
| `kling-sheet-1..5.webp` | **Новые листы из Kling AI 3.0 (получены 17.10.2026), 2000×1500.** Сохранены для СЛЕДУЮЩИХ роликов: позы, лица, ракурсы, сцены. Пока не нарезаны. |
| `walk-reference.mp4` | 5-секундный образец анимации (профессор идёт по улице). |

## Как использовать kling-листы (когда понадобится)

- Резать тем же способом, что и `sheet-a/b` (`tools/prof/assets.py`: вырез с прозрачным фоном, ×4, стикерный контур). Эти листы крупнее, лица получатся чётче.
- **Нельзя брать:** водяной знак «KlingAI 3.0» в правом нижнем углу каждого листа; панели с надписями-«абракадаброй» (псевдотекст на досках и заголовках секций); панели, где персонаж «поплыл» (женские версии, лысый, с бородой, в наушниках-очках, галстук, лишние персонажи).
- Брать: крупные лица и позы, где это явно наш профессор (чёрная водолазка, пиджак, круглые очки, каштановая чёлка): ряды поз с указкой, скрещёнными руками, руки в карманах; крупные планы с лупой, задумчивое лицо с рукой у подбородка, сидит в кресле с планшетом/чашкой, лежит, идёт с рюкзаком.
- Перед нарезкой посмотреть лист глазами и подобрать рамки вручную (как в `ITEMS` в `tools/prof/assets.py`).
