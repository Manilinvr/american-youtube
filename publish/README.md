# Публикация на YouTube

Для каждого ролика в этой папке лежит `sNNN-*.md` — всё для копирования: название, описание, хэштеги, теги, закреплённый комментарий.

> **Субтитры уже вшиты в видео** (рукописные, с жёлтым маркером). Отдельные субтитры в YouTube **не загружайте**: у зрителей с включёнными субтитрами (CC) YouTube рисует поверх видео белые строки на тёмной плашке, и они закрывают наши. Файлы `.srt` в этой папке — только запасной вариант (например, для переводов), загружать их не нужно.

## Настройки при загрузке (одинаковые для всех роликов)

| Поле | Значение | Почему |
|---|---|---|
| **Аудитория** | **Нет, это видео не для детей** | Иначе отключатся комментарии и персонализированная реклама |
| **Изменённый или синтетический контент** | Нет | Метка нужна для реалистичного контента, который можно принять за настоящий. Рисованный мультфильм под это не подпадает. Озвучка — синтетическая, но это не имитация реального человека |
| **Категория** | Образование (Education) | Психология и исследования; YouTube показывает такие ролики людям, которые смотрят научпоп |
| **Язык видео / субтитров** | English | Аудитория — США |
| **Субтитры** | **Не загружать.** После публикации: Studio → Субтитры → выбрать видео → у строки «Английский (автоматически)» нажать ⋮ → **Отменить публикацию** (или «Удалить») | Наши субтитры уже вшиты в видео; белые субтитры YouTube закрыли бы их у зрителей с включённым CC |
| **Лицензия** | Стандартная лицензия YouTube | — |
| **Разрешить ремиксы** | Да | Ремиксы Shorts бесплатно приводят новых зрителей |
| **Комментарии** | Включены, «Удерживать потенциально неприемлемые» | Комментарии — главный сигнал вовлечения |
| **Плейлист** | Создайте **«The Specimen Catalogue»** и добавляйте туда каждый выпуск | Каталог видов = сериал, который хочется досмотреть |
| **Связанное видео** (Shorts → Related video) | Ссылка на следующий/предыдущий выпуск | Зритель уходит не из ленты, а в следующий ваш ролик |

## Хэштеги: как это работает

- Ставим **3–5 хэштегов** в конце описания: 1–2 широких (`#psychology`, `#relatable`), 1–2 тематических (`#memory`, `#procrastination`), `#shorts`. Больше — хуже: YouTube начинает игнорировать.
- Первые три хэштега YouTube показывает над названием — поэтому первым ставим самый «поисковый» тематический.
- Один хэштег можно добавить в название, но не обязательно.

## Порядок и время

1. **#001 The Doorway Forgetter** — первым: самый узнаваемый хук.
2. **#002 The Last-Minute Genius** — через 2–3 дня.
3. **#003 The Shower Philosopher** — ещё через 2–3 дня.

Время: для США начните с **будних дней 12:00–15:00 или 18:00–21:00 по Нью-Йорку (ET)** и через 2–3 недели сверьтесь с YouTube Studio → Аналитика → «Когда ваши зрители на YouTube».

## Первый час после публикации

1. Закрепите комментарий из файла ролика.
2. Отвечайте на каждый комментарий в стиле канала: *"Field note: Specimen #001 confirmed. 🔬"*
3. Поделитесь роликом в сообществе канала/других соцсетях — первые просмотры помогают алгоритму понять, кому показывать.

## Обложка Shorts

В мобильном приложении YouTube при загрузке выберите кадр, где на экране **карточка вида и персонаж** (момент, когда карточка «шлёпается» после слова *Specimen*, примерно 4–6 секунда). Это фирменный кадр канала, его узнают в ленте.
