# Бесплатная ИИ-озвучка

## Что выбрано: Kokoro TTS

| | |
|---|---|
| Лицензия | **Apache 2.0** — можно использовать в монетизируемых видео, без указания авторства |
| Где работает | Локально, на обычном процессоре, **без интернета и без лимитов** |
| Скорость | ~1–3 секунды генерации на фразу |
| Размер | ~350 МБ (скачивается автоматически при первом запуске в `models/`) |
| Качество | Одно из лучших среди открытых моделей для американского английского |

Голос канала — **`af_heart`**: самый естественный голос Kokoro, мягкая неторопливая подача (тоны в `config/tones.json`). Голос смягчается эквалайзером прямо при генерации (убирает резкие «с»/«ш»), а финальный ролик выводится на спокойную громкость **−16 LUFS** (`config/channel.json` → `loudness`). Посмотреть все голоса:

```bash
python3 tools/tts/voice.py --voices
```

**Совет:** выберите **один** голос рассказчика на весь канал — он становится узнаваемым, как голос ведущего.

### Уникальный голос канала (смешивание)

Kokoro умеет смешивать голоса — получается голос, которого нет ни у кого:

```json
"voice": { "name": "bf_emma:70,bf_isabella:30" }
```

### Интонация

У Kokoro нет «ползунка эмоций», поэтому настроение делаем так:

- **Тоны** (`config/tones.json`): `documentary` (основной, мягкая неторопливая подача), `deep` (медленнее, длинные паузы — для вывода), `funny` (быстрее — для вердикта и шуток). Тон можно задать всему ролику и отдельной сцене.
- **Пунктуация:** `...` — драматическая пауза, `?` — вопросительная интонация, короткие предложения — «панчи». `Every. Single. Time.` звучит как три удара.
- **Произношение:** `[4%|four percent]` — в субтитрах «4%», а голос читает «four percent». Числа, аббревиатуры и имена лучше записывать так.

## Chatterbox — максимально человеческий голос (второй движок)

[Chatterbox](https://github.com/resemble-ai/chatterbox) от Resemble AI — открытая модель под лицензией **MIT** (монетизация разрешена), в слепых тестах производителя её часто путают с живым человеком. Она медленнее Kokoro (на обычном процессоре ≈ 8 секунд работы на 1 секунду речи, 30-секундный шортс — около 4–5 минут), зато интонации живые. Умеет «клонировать» голос по 10-секундному образцу: `config/voices/narrator.wav` — это образец af_heart, так что Chatterbox говорит тем же тембром, но живее.

Включить — одна строка в `config/tones.json` (или `voice` в сценарии):

```json
"voice": "chatterbox:config/voices/narrator.wav"      // тембр канала, живая интонация
"voice": "chatterbox"                                  // стандартный голос Chatterbox
```

Установка (один раз, отдельное окружение, ~2 ГБ):

```bash
uv venv -p 3.11 .venv-chatterbox
VIRTUAL_ENV=.venv-chatterbox uv pip install --index-url https://download.pytorch.org/whl/cpu \
  --extra-index-url https://pypi.org/simple --index-strategy unsafe-best-match \
  torch==2.6.0 torchaudio==2.6.0 chatterbox-tts==0.1.7 "setuptools<81"
```

Если есть видеокарта NVIDIA, уберите строку с `--index-url .../cpu` — будет в десятки раз быстрее. Настройки подачи (спокойнее/выразительнее) — константы `EXAGGERATION` и `CFG_WEIGHT` в `tools/tts/chatterbox_batch.py`.

## Сравнение бесплатных вариантов

| Вариант | Цена | Можно монетизировать? | Качество | Комментарий |
|---|---|---|---|---|
| **Kokoro** (основной) | бесплатно, локально, быстро | да (Apache 2.0) | высокое | Встроен в проект |
| **Chatterbox** (встроен вторым движком) | бесплатно, локально | да (MIT) | **очень высокое, живые интонации**, клон голоса | Медленнее; см. раздел выше |
| Orpheus (Canopy Labs) | бесплатно, локально | да (Apache 2.0) | очень высокое, эмоции `<sigh>`, `<laugh>` | Нужна видеокарта (3B параметров) |
| Fish Audio S2 | бесплатно для исследований | **нет** без платной лицензии | топ по бенчмаркам | Для монетизации нужна коммерческая лицензия |
| Coqui XTTS-v2 | бесплатно | **нет** (некоммерческая лицензия) | высокое | Не подходит для монетизируемого канала |
| Piper | бесплатно, локально | зависит от лицензии конкретного голоса | среднее | Очень быстрый, но звучит роботизированнее |
| edge-tts (голоса Microsoft Edge) | бесплатно, онлайн | **рискованно** — неофициальный доступ к сервису | высокое | Может перестать работать в любой момент; для монетизируемого канала не рекомендую |
| ElevenLabs Free | бесплатно с лимитом | **нет** на бесплатном тарифе | очень высокое | Коммерческое использование только на платных тарифах |

Лицензии и условия сервисов меняются — перед запуском монетизации перепроверьте страницы лицензий.

## Технические детали

- Каждая фраза озвучивается по предложениям, паузы между ними контролируются тоном.
- Громкость каждой фразы выравнивается, а финальный ролик нормализуется до **−16 LUFS** (спокойнее стандартных −14) командой `npm run make`.
- Озвучка кэшируется: если текст сцены не менялся, повторно не генерируется.
- Тайминг слов для субтитров оценивается по длине слов внутри каждого предложения (точности хватает для субтитров по 2–3 слова).
