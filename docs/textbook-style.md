# Стиль «Иллюстрированный учебник» (Everyday Psychology)

Второй визуальный стиль фабрики: **винтажный иллюстрированный учебник психологии, оживлённый документальной камерой**. Работает на том же конвейере (сценарий JSON → озвучка af_heart → Remotion → MP4), но рисует не скетч, а **один разворот-«таблицу» (Plate) из панелей**, по которому путешествует камера. Первый ролик в этом стиле: [`episodes/ep001-night-thoughts.json`](../episodes/ep001-night-thoughts.json).

## Палитра (зафиксирована, `src/textbook/palette.ts`)

| Токен | Цвет | Где |
|---|---|---|
| paper | `#E9DFC9` | лист |
| parchment | `#F3EBDD` | светлые панели, бирки |
| ink | `#292722` | контуры, текст, тёмные панели |
| brown | `#806348` | дерево, подписи |
| ochre | `#C49A59` | свет лампы, импульсы, акценты на тёмном |
| terracotta | `#B96F50` | «красная ручка» учебника: петля мыслей, выводы |
| blue | `#849BA2` | ночь, одеяло |
| olive | `#929078` | одежда персонажа |
| black | `#242321` | стол под листом, тени |

Смеси (кожа, ночная стена, тёплое свечение) — только из этих цветов. Никаких насыщенных цветов, неона, глянца, 3D.

## Линия и фактура

- **Контур** (`<Ink>`): тушь с лёгкой неровностью — второй тонкий проход со смещением 0.7 px; геометрия «дрожит» по сиду (`rough.ts`), но **не кипит** от кадра к кадру: в книге линии неподвижны, жизнь даёт движение.
- **Заливка** (`<Fill>`): цвет печатается со сдвигом 1.4 px от контура (офсетная печать), сверху — «потёртость краски» (`tb-wear`).
- **Штриховка**: векторные паттерны `tb-light / tb-mid / tb-dense / tb-cross / tb-stipple` — гравюрные тени, остаются чёткими при любом наезде.
- **Бумага**: пятна старения, фокусные точки, затемнённые края листа (в координатах страницы) + зерно плёнки, пылинки и виньетка поверх кадра.

## Персонаж

Один и тот же человек во всех панелях (`src/textbook/figures.tsx`): круглая голова, маленькие точки-глаза, короткие брови, каштановые волосы с пробором, оливковый свитер с охристым воротом. Эмоция — позой и бровями, а не гримасой. Глаза моргают, одеяло «дышит».

## Научные рисунки

- Анатомия рисуется как в старом атласе: тонкая тушь, пунктирная штриховка, подписи с выносками (`<Callout>`).
- **Метафора всегда подписана как метафора** («a thought loop (conceptual)», «the racing sparks are a metaphor, not a measurement»), анатомия — как упрощение («simplified, not to scale»).
- Цвет кодирует смысл: мысль — терракота, анатомия — тушь. Когда петля мыслей «входит» в нейрон, нить меняет цвет на границе метафоры и анатомии.

## Типографика

- IM FELL English / SC (OFL, `public/fonts`) — заголовки плиты, тёмные панели, подписи `fig.`.
- Kalam — рукописный список в блокноте и наши вшитые субтитры (в этом стиле: охристый маркер, терракотовые выделения, пергаментная подложка).

## Как устроен ролик

```jsonc
"page": {                                  // один разворот на весь ролик
  "width": 1080, "height": 2070,
  "plate": "Plate I.", "title": "The Night Mind", "subtitle": "...",
  "caption": ["Plate I. ...", "Fig. 1, ..."],          // подпись под таблицей
  "panels": [ {"id": "room", "x": 44, "y": 176, "w": 992, "h": 600,
               "tone": "night", "art": "bedroom", "fig": "fig. 1 — ..."} ],
  "threads": [ {"points": [[459,977], ...], "at": "thread"} ]   // линии через поля
},
"scenes": [{
  "id": "name", "say": "...", "transition": "cut",     // мир один — склеек нет, двигается камера
  "visual": {
    "type": "page",
    "events": {"rnt": "repetitive", "alert": "alert"},  // именованные события на словах
    "camera": [ {"panel": "loop", "zoom": 2.6, "focus": [0.93, 0.4], "secs": 1.0},
                {"at": 0.7, "panel": "neuron", "secs": 1.9},
                {"at": "rest", "page": true} ],          // отъезд на весь лист
    "sfx": [{"at": "writing", "name": "scribble", "volume": 0.2}]
  }
}]
```

- Камера: ключ `panel` кадрирует панель (или несколько) над зоной субтитров, `zoom`/`focus` уточняют, `page: true` — отъезд на весь лист, лежащий на столе. После каждого движения — медленный «дрейф» (+0.5 %/с).
- «Лампа над книгой»: освещена панель, на которую смотрит камера, остальная страница в мягкой тени.
- Панель **прорисовывается при первом визите** камеры (линии — штрихом, заливки — проявлением), поэтому к финальному отъезду таблица заполнена целиком.
- Параллакс: внутри панелей слои (`parallax(a, depth)`) смещаются с разной скоростью при движении камеры.
- Иллюстрации — React-компоненты в `src/textbook/art/` (регистрируются в `art/index.ts`) и получают время через `useArt()`: `prog(a, 'event', dur)`, `since`, `wave`, `blinking`.

## Проверка

```bash
node tools/stills.mjs <id> 0 300 12.5s --browser-executable=...   # кадры в out/stills/<id>/
npm run make -- <id> --browser-executable=...                   # полный рендер + громкость
```
Смотреть: ничего не обрезано, подписи читаются при наезде, метафоры подписаны, субтитры не перекрывают ключевую часть рисунка, финальный отъезд показывает всю таблицу.
