# Темы для стиля «иллюстрированный учебник» (epNNN)

Отбор: узнаваемая ситуация + настоящий эффект с исследованием + хорошая «научная» картинка (мозг, память, внимание, схема) + повод для анимации персонажа. ✅ — надёжные данные; ⚠️ — данные есть, но формулируем осторожно («some research suggests»). Перед производством каждый факт перепроверяется поиском (правило 8 из `CLAUDE.md`).

## Что меняем в производстве

- **Больше кадров:** 10–12 панелей на таблицу (вместо 9), смена плана каждые 3–4 с, у каждой панели свой момент анимации персонажа.
- Где тема просит — **два разворота** с перелистыванием страницы между ними.
- Повторяющийся персонаж и мотив (как петля мыслей в ep001) — свой для каждой темы.
