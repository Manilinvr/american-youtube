## Рынок и данные
- **Котировки Yahoo** годятся для 10 пар, кроме **EURUSD**: ~21% 15-минутных свечей «замирают» (open = close). Для EURUSD нужен другой источник — у Deriv свечи нормальные (5 знаков).
- **Свечи Deriv** (`ticks_history`, candles): за запрос ~800 свечей; последняя свеча — незакрытая (отбрасывать), первая может быть неровной.
- **Ночь 21:00–02:00 МСК** — стабильно худшее время (закрытие Нью-Йорка, ролловер, широкие спреды). Остальной профиль «прибыль по часам» между периодами не повторяется (research/time_analysis_*.md).
- На 15m движения чаще откатывают, чем продолжаются (отрицательная автокорреляция, особенно USDCAD, GBPUSD, USDCHF, EURGBP) — reports/market_10y.md.
- Новости: фильтр ±30 мин и выход за 15 мин до новости улучшил 38 из 59 схем на истории (reports/news_filter_effect.csv).

## Экономика бинарных опционов
- Безубыточный винрейт = 1 / (1 + выплата): 95% → 51.3%; 85% → 54.1%; **82% (Deriv 30/60 мин) → 55.0%**; 75% → 57.1%.
- **Реальная выплата важнее схемы.** Неделя 09–13.11: при 95% — +$466 по всем 121 варианту, по выплатам Deriv — −$11 019. Всегда проверять реальную выплату перед сделкой.
- Deriv Rise/Fall: 30 и 60 мин — ~81.8% по всем парам; 15 мин — от ~70–75% (EURUSD, GBPUSD, NZDUSD, EURGBP) до ~88–92% (USDJPY, USDCAD, USDCHF, GBPJPY). Выплаты логируются в deriv/payouts.csv.
- Ничья (цена в момент экспирации = цене входа) — возврат ставки; не считать выигрышем.

## Схемы
- Неделя 1: в бинарной модели лучше всего — **схемы «на откат»** (Три экрана Элдера, Боллинджер во флэте, RSI(2), Двойная семёрка); трендовые/пробойные — хуже.
  В модели «форекс со стопами» — наоборот: выигрывают трендовые (Черепахи, пробой Нью-Йорка), «на откат» проигрывают (стоп больше тейка).
- **Отбор по 3 дням — шум**: пары-лидеры пн–ср стали худшими в чт (счёт $1000 12.11 → $875). Выбирать схемы/пары только на 2+ неделях данных.
- Схем с ≥70% выигрышных при ≥20 сделках и плюсе — пока нет (ближе всех 67–69%).

## Риск и счёт
- Без лимита риска счёт форекса 13.11 ушёл бы до −$10 после стопа (открытые сделки продолжают проигрывать). Правило: новая сделка — только если баланс останется ≥ $100 при проигрыше всех открытых.
- Пятница 13.11: Pocket Option достиг бы цели $2000 к 14:45, но в течение дня падал до ~$200–270 — внутри дня колебания очень большие.

## Методика
- Правила работающих схем не менять; улучшение = новая схема с новым id и стартом с понедельника.
- Любой вывод проверять вне выборки (walk-forward); «лучшие часы/пары» одной недели почти всегда шум.
- Теневые журналы (все часы, режим после цели) — чтобы честно проверять фильтры.

## Площадки
- Pocket Option: нет официального API; офшор без лицензии (FCA и др. предупреждения). Не автоматизировать, не давать паролей.
- Deriv: новый API `api.derivws.com` (PAT + заголовок Deriv-App-ID, WebSocket по одноразовому OTP); торговать только на демо (DOT…); реальный счёт ROT… не трогать.
- GitHub Actions: запуск командой (workflow_dispatch) работает только для файлов в основной ветке репозитория (сейчас claude/gracious-dirac-93w3vb).
- 13.11 пробная сделка через API прошла: CALL USDJPY 15 мин, $1, payout $1.73, contract 20477877839. Покупка: `{"buy": proposal_id, "price": stake}`; статус: `proposal_open_contract` (status, is_sold, profit, entry_spot, date_expiry). В proposal поле пары — `underlying_symbol` (не `symbol`); CALL = «строго выше цены входа».
- **Ничья у Deriv = проигрыш** (условие «строго выше/ниже цены входа»); вход — по следующему тику после покупки, а не по открытию свечи. На Pocket Option ничья в нашей модели — возврат.
- Выходные исследования (research/weekend_ideas_2026-11-14.md): чтобы угадывать 58% на 60 мин, нужен устойчивый сдвиг ~0.2σ (~2–2.5 б.п./час); известные академические внутридневные эффекты дают лишь 51–53% — годятся как фильтры, а не как самостоятельные схемы. Отличить 58% от 55% можно только на ~730 независимых сделках.
