# Deriv: настоящие демо-сделки «вверх/вниз» (Rise/Fall)

Решение владельца 13.11.2026: торговать демо-счёт на Deriv (аналог Pocket Option с официальным API).

## Что выяснили (13.11, пт ~21:45 МСК; проверено и отсюда, и из GitHub Actions)
- Новый API Deriv: `wss://api.derivws.com/trading/v1/options/ws/public` (публичные данные без ключа),
  торговля — `.../ws/demo?otp=...` (одноразовый пароль получают по REST с ключом PAT и заголовком `Deriv-App-ID`).
- Валютные пары есть все наши 10 (`frxEURUSD` и т. д.), свечи 15m/1h — через `ticks_history`.
- **Выплаты Deriv (ставка $20):** экспирация 30 и 60 мин — **81.8%** по всем парам; 15 мин — от 70% (EURUSD) до 92% (USDCHF).
  Безубыточность при 82% — **55%** выигрышных сделок (при 95% в модели Pocket Option — 51.3%).
- Пересчёт недели 09–13.11 по выплатам Deriv: все 121 вариант — **−$11 019** (при 95% было +$466);
  74 схемы, оставшиеся после чистки, — **−$580** (при 95% — +$6 416); 39 из 71 схем в плюсе.

## Подключение (делает владелец)
1. Зарегистрироваться на deriv.com (демо-счёт создаётся сразу).
2. На developers.deriv.com → Dashboard: создать приложение типа **PAT** → получить **App ID**.
3. Там же создать **Personal Access Token** со scope **trade** (без admin/payments).
4. В GitHub: репозиторий → Settings → Secrets and variables → Actions:
   - секрет `DERIV_TOKEN` = токен (никому не пересылать, в чат не вставлять);
   - App ID уже сохранён в `trader/deriv/config.json` (не секрет).
