# Трейдер: демо-обучение на валютных парах

Цель — за 2 месяца демо-торговли (9 ноября 2026 — 8 января 2027) найти торговые
схемы с винрейтом ≥ 70% **и** итогом в плюсе. Реальные деньги не используются.

## Площадка: Pocket Option (бинарные опционы)
- Ставка $20 «вверх/вниз» на фиксированное время (экспирация 15, 30, 60 мин).
- Выигрышная сделка — +$20 × выплата (при 95% = +$19), проигрышная — −$20, ровно по цене — возврат.
- Сделки совершаются строго по правилам схемы, без «угадывания».
- Только валютные пары с выплатой ≥ 85% (`pocketoption.json` — выплаты обновлять по платформе), **без OTC**
  (только будни, реальный рынок), без ставок во время важных новостей.
- Расчёт по указанию владельца: выплата 95% для всех пар. Безубыточный винрейт — **51.3%**; при 70% выигрышей в среднем +$7.3 на ставку.
- Расчёт — `binary.py`; режим переключается в `backtest.py` (`MODE = "binary"` / `"cfd"`).

## Две модели параллельно (решение владельца 13.11)
Одни и те же схемы торгуются сразу в двух моделях, у каждой свой журнал и отчёты:
| Модель | Журнал | Отчёты | Запуск |
|---|---|---|---|
| Pocket Option (бинарные опционы) | `journal/` | `reports/daily/ДАТА.md`, `reports/weekly/ДАТА.md` | `python3 paper.py daily` |
| Форекс со стопами (первая версия: плечо, стоп-лосс/тейк-профит, риск $20) | `journal/cfd/` | `reports/daily/ДАТА_cfd.md`, `reports/weekly/ДАТА_cfd.md` | `TRADER_MODE=cfd python3 paper.py daily` |

## Правила владельца
- Торгуем валютными парами, сделки от 15 минут (таймфреймы 15m и 1h).
- 13.11 (по итогам первой недели) исключаются все схемы с минусом за неделю.
- Дальше: если схема за любые 2 недели демо-торгов ушла в минус — она исключается навсегда.
- Хорошая схема: винрейт ≥ 70% и итог в плюсе (от 20 сделок).
- Отчёт — в 21:10 МСК: вс–чт ежедневный, в пятницу недельный (в нём и итог дня); в субботу рынок закрыт, вечер пятницы попадает в воскресный отчёт.

## Команда
| Кто | Чем занимается | Файлы |
|---|---|---|
| Зам (главный агент) | собирает всё вместе, исправляет, решает, пишет отчёт | всё |
| Исследователь стратегий | книги, статьи, форумы → точные правила | `research/strategies.md`, `research/sources.md` |
| Аналитик «китов» | отчёт CFTC COT: позиции хедж-фондов и крупных управляющих | `cot.py`, `reports/cot_latest.md` |
| Робот-трейдер (программа) | торгует по правилам на демо, ведёт журнал | `engine.py`, `strategies.py`, `paper.py` |

## Как устроено
- `fetch.py` — котировки 10 пар с Yahoo Finance (15m за 60 дней, 1h за 2 года, 1d за 10 лет),
  каждый запуск дописывает новые свечи в `data/`.
- `engine.py` — честный тест: вход по открытию следующей свечи, спред вычитается (ночью ×3),
  если в одной свече задеты и стоп и тейк — считаем стоп.
- `strategies.py` — 31 схема (Коннорс, Рашке, Лин, Элдер, Брукс, Уильямс, Крэбел, Остлер, ICT...).
  Правила запущенной схемы не меняются; улучшение = новая схема с новым id.
- `backtest.py` — проверка всех схем на истории → `reports/backtest.md`.
- `paper.py` — демо-торговля вперёд, журнал `journal/trades.csv`, статусы `journal/status.json`,
  пятничный отчёт `reports/weekly/ДАТА.md`.
- `news.py` — календарь важных новостей (ForexFactory + даты ФРС). Для всех схем: не входить
  за 30 мин до и 30 мин после новости по валютам пары, закрывать сделку за 15 мин до новости,
  не входить после аномальной свечи (> 3 ATR). На истории фильтр улучшил 38 схем из 59
  (`reports/news_filter_effect.csv`).
- `cot.py` — позиции «китов» по данным CFTC → `reports/cot_latest.md`.
- `market_study.py` — обзор рынка за 10 лет → `reports/market_10y.md`.

## Запуск
```bash
cd trader
python3 fetch.py && python3 cot.py && python3 paper.py report   # пятница
python3 fetch.py && python3 paper.py daily                     # остальные дни
TRADER_MODE=cfd python3 paper.py daily                         # то же для форекса со стопами (в пятницу — report)
python3 account.py accounts/challenge_ДАТА.json                # счёт с балансом (задание владельца)
```
