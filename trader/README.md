# Трейдер: демо-обучение на валютных парах

Цель — за 2 месяца демо-торговли (9 ноября 2026 — 8 января 2027) найти торговые
схемы с винрейтом ≥ 70% **и** итогом в плюсе. Реальные деньги не используются.

## Правила владельца
- Торгуем валютными парами, сделки от 15 минут (таймфреймы 15m и 1h).
- Каждая сделка — риск **$20** (стоп = −$20, прибыль = $20 × тейк/стоп).
- Если схема за любые 2 недели демо-торгов ушла в минус — она исключается навсегда.
- Хорошая схема: винрейт ≥ 70% и итог в плюсе (от 20 сделок).
- Отчёт — каждую пятницу после 21:00 (МСК).

## Команда
| Кто | Чем занимается | Файлы |
|---|---|---|
| Зам (главный агент) | собирает всё вместе, исправляет, решает, пишет отчёт | всё |
| Исследователь стратегий | книги, статьи, форумы → точные правила | `research/strategies.md`, `research/sources.md` |
| Аналитик «китов» | отчёт CFTC COT: позиции хедж-фондов и крупных управляющих | `cot.py`, `reports/cot_latest.md` |
| Робот-трейдер (программа) | торгует по правилам на демо, ведёт журнал | `engine.py`, `strategies.py`, `paper.py` |

## Как устроено
- `fetch.py` — котировки 10 пар с Yahoo Finance (15m за 60 дней, 1h за 2 года, 1d за 10 лет),
  каждый запуск дописывает новые свечи в `data/`.
- `engine.py` — честный тест: вход по открытию следующей свечи, спред вычитается (ночью ×3),
  если в одной свече задеты и стоп и тейк — считаем стоп.
- `strategies.py` — 31 схема (Коннорс, Рашке, Лин, Элдер, Брукс, Уильямс, Крэбел, Остлер, ICT...).
  Правила запущенной схемы не меняются; улучшение = новая схема с новым id.
- `backtest.py` — проверка всех схем на истории → `reports/backtest.md`.
- `paper.py` — демо-торговля вперёд, журнал `journal/trades.csv`, статусы `journal/status.json`,
  пятничный отчёт `reports/weekly/ДАТА.md`.
- `cot.py` — позиции «китов» по данным CFTC → `reports/cot_latest.md`.
- `market_study.py` — обзор рынка за 10 лет → `reports/market_10y.md`.

## Запуск
```bash
cd trader
python3 fetch.py && python3 cot.py && python3 paper.py report
```
